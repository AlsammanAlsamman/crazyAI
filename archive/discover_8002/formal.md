Setting aside the object itself, what's left is not one structure but four distinct formal ingredients wired together — and it resists collapsing into a single clean statement. Reporting that plainly seems more honest than forcing it.

**1. Quantized stochastic displacement.**
Movement distance is the count of "on" outcomes among several independent binary trials (four sticks, each light/dark) — i.e., the state advances by a draw from a Binomial(n, p) variable rather than a fixed or continuous step. This part is clean and standard: sum-of-Bernoulli-trials as step size.

**2. A transition rule indexed by an external, independently-running clock.**
Which axis the step is *applied along* is not fixed by the piece's own state but by the phase of a separate oscillating process (the moving light) that has its own period, decoupled from the dice draws and from the piece's position. So the same random outcome produces different actual moves depending on where two independent cycles — the stochastic one and the periodic one — happen to coincide. This is closer to a phase-gated or time-inhomogeneous transition function: the rule set itself is a function of an external clock, requiring the state to be re-interpreted at every step rather than read off a fixed table.

**3. A path with no terminal object.**
The space that would complete the trajectory is explicitly excluded from the space's definition — not merely hard to reach, but structurally absent (an open boundary, not a closed one you fail to attain). This turns the object from a race-to-a-goal process into a pure measure of ongoing transit: the quantity being tracked is displacement/traversal itself, with no absorbing state anywhere in the model. Formally: a process on a half-open interval, valued for its trajectory, where "completion" isn't a low-probability event but a category error — there's nothing there to arrive at.

**4. Capture as covering, not deletion — a conservation law.**
When one element supersedes another at the same position, the superseded one isn't removed from the underlying set; it's placed in a dominance/order relation beneath the active one, retaining its own future turn. Total cardinality of the system is invariant under this operation — only the relation among elements (who is "on top," whose turn is deferred) changes. This is a stack-like (LIFO) or covering-relation structure layered on top of the position space, distinct from a simple set-difference "removal."

**What doesn't reduce:** items 1–2 are dynamics (how the state changes step to step, with an unusual twist that the applicable rule itself cycles externally); item 3 is a statement about the shape of the state space (no terminus); item 4 is an algebraic/order-theoretic property of the "removal" operation (conservation + subsumption instead of deletion). These are three different kinds of formal claim — about a random variable, about a set's boundary, and about an operation's invariants — and nothing forces them into one equation or one named structure. The honest summary is: a bounded, open-ended path traversed by quantized random steps under a rule that must be re-read against an independently cycling index, on which no operation ever deletes an element, only re-orders it beneath another while preserving the count and the entitlement to act again.
