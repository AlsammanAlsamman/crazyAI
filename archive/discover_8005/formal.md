**Core structural elements, stripped of the marbles/glass/water:**

1. **One shared degree of freedom, N encoded read-outs.** There are N distinguishable slots, each carrying an "identity value," but the slots are not independently addressable — they are all functions of a *single* underlying parameter (the loop's one rotational state). Perturbing any one slot's apparent value is not really an edit to that slot; it's a change to the shared parameter, which every slot re-displays according to its own fixed offset. So the system has N apparent variables but exactly 1 true degree of freedom. Privacy of edit is structurally impossible, not just socially discouraged — there is no coordinate in the system's actual state space that corresponds to "change mine alone."

2. **Encoding with a narrow decoding condition.** Each slot's value is stored in a transformed (bent) rather than plain form, and the inverse transform back to the plain value only holds at one specific viewing condition (one angle) out of a continuum of possible ones. Elsewhere in that continuum the value is not partially true — it is simply illegible. This is a threshold/trapdoor relationship between encoding and decoding, not a graded one.

3. **A second channel that leaks the decoded value ahead of the first.** Beyond the direct object-plus-correct-angle path to the plain value, there exists an indirect, derived channel (the reflection) that outputs the same plain value without requiring the viewer to find the correct angle at all — and it does so *first*, temporally preceding the direct read. So there are two routes to the same decoded information, asymmetric in both required conditions and arrival time, and the easier/faster one is treated as the authoritative one.

4. **Access to your own read-out is gated by traversal of the others'.** Reaching the condition under which your own slot decodes requires physically/procedurally passing through the decoding conditions of the other N−1 slots first. Self-information is not randomly addressable; it sits at the end of an ordered path through everyone else's information.

5. **A rejected shortcut that would flatten the threshold.** There is an alternative condition (uniform bright light) that would make all N slots simultaneously legible from any angle, collapsing the threshold/traversal requirement — and this shortcut is explicitly deemed illegitimate ("glare," not truth), i.e., the structure encodes a normative claim that ease-of-decoding-under-uniform-conditions produces a different (lesser) epistemic status than decoding-under-the-narrow-condition-plus-traversal, even though the output value would be identical.

**Does it reduce to one clean formal object?** Not quite. Pieces 1–2 together resemble a single conserved quantity acted on by a group, observed through N phase-shifted projections each requiring its own inverse map (something like one hidden variable, N gauge-dependent measurement bases, one of which is "correct" per slot). Piece 3 breaks that clean picture by adding a second, non-gauge-dependent measurement channel with its own time-ordering relative to the first — that's not part of the same algebraic structure, it's a separate epistemic/temporal claim bolted on. Piece 4 adds a further constraint that isn't about the values at all but about the *order of access* to them (a path/graph property, not a value property). Piece 5 adds a normative ranking between two conditions that yield the same output. So the honest answer: there's a clean algebraic core (one global parameter, N gauge-dependent local views, no independent local edits) wrapped in at least two additional, structurally different claims (a privileged faster/prior channel to the same fact, and an ordering/access constraint plus a legitimacy ranking on how that fact may be obtained) that do not collapse into the same formalism as the core. It's a composite, not a single shape.
