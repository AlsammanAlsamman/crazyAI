**Two connections that hold up; one that's more restatement than insight.**

**1. Incremental sentence processing / garden-path effects (psycholinguistics, computational linguistics)**
Structure used: (1)+(2). Model each word's local ambiguity as exactly the tree in (1): richer/more constraining context → deep, low-branching continuation set; impoverished or ambiguous context → shallow, wide one. The parser's commitment state maps onto (2) directly: "undetermined" = holding multiple parses in parallel (a packed parse forest, as in chart/Earley parsing), "fixed" = collapsed onto one serial analysis (Frazier-style garden-path parsing). This isn't a stretch — it's essentially the entropy-reduction hypothesis (Hale 2003, Frank 2013): processing difficulty at a word tracks the drop in entropy over possible continuations from before to after that word.
*Check:* Take a PCFG or a next-token LM, compute branching entropy per word over an existing eye-tracking/self-paced-reading corpus (Dundee, Provo, etc.), and correlate entropy-reduction with reading time / regression rate. A forced disambiguation point (classic garden-path sentence) should show a sharp entropy collapse coinciding with a reading-time spike. This is fully checkable against data and models that already exist — no new instrumentation needed.

**2. Time-to-commitment from evidence-accumulation trajectory shape (decision neuroscience)**
Structure used: (2)+(3), taken honestly as a hypothesis rather than a working mechanism — which is exactly how the source text treats it (an asserted skill, not a derivation). In drift-diffusion/race models of perceptual decisions, "undetermined" = a bounded random walk before threshold crossing, "fixed" = the crossing itself. The claim worth testing is (3)'s actual content: does the *local shape* of the accumulation trace (recent velocity, curvature, variance) carry information about *remaining time to commitment* beyond what current position + known drift/noise parameters already imply? Under a clean stationary DDM the answer is trivially "no" (hitting time is already a deterministic function of position); if real data say otherwise, that's a genuine finding about hidden non-Markovian state — a real, currently open question in the urgency-signal literature (Churchland/Kiani/Shadlen-style ramping activity in LIP/FEF).
*Check:* Fit a standard DDM to an existing perceptual-decision dataset (random-dot-motion recordings, IBL data), then regress remaining time-to-boundary on windowed trajectory-shape features vs. current accumulator value alone, out of sample. A statistically reliable gain from shape features over position alone would validate the "clock encoded in shape" idea in this domain; no gain would falsify it cleanly.

**3. Ambient entrainment (structure 4) — flagged, not proposed**
This maps onto real phenomena (theta–gamma cross-frequency coupling, Kuramoto synchronization between competing pacemakers), but those are already well-established descriptions in their own right — the metaphor doesn't add a new question, testable prediction, or mechanism beyond what phase-locking-value/coupling-index methods already measure. Including it would be restating known neuroscience under new vocabulary rather than the structure actually doing explanatory work, so I'm not counting it as a genuine application, per the "don't force it" instruction.
